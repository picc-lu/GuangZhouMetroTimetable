# 广州地铁 · 运营时间展示

一个纯前端的广州地铁（含佛山地铁、有轨电车）运营时间查询页面。支持实时获取官方首末班车数据、自定义时间模拟、换乘线路提示、多终点站展示等功能。无需后端，直接部署静态文件即可运行。

---

## 功能特性

- **实时数据获取**：调用广州地铁官方接口获取线路、站点及首末班车时间，数据每日自动更新。
- **每日 5:00 自动刷新**：页面在凌晨 5:00 自动拉取最新数据（适用于页面长时间挂机）。
- **本地缓存**：当日数据缓存到 `localStorage`，避免每次刷新都请求接口。
- **自定义时间模拟**：支持指定任意时间，查看该时刻各线路的运营状态。
- **多终点站显示**：如 5 号线等线路，可分别展示不同终点站的首末班车时间。
- **换乘线路提示**：
    - 站点下方自动显示可换乘的线路标签；
    - 换乘线路若当前已停运，标签自动变灰；
    - 有轨电车与地铁的换乘通过人工映射 + “出”字标识，提示出闸换乘；
    - 点击换乘标签可跳转到对应线路详情。
- **线路详情弹窗**：
    - 竖向线路图展示各站运营时间；
    - 顶部悬浮图例显示方向与终点站；
    - 显示当前时间与自定义时间模式提示；
    - 自动 30 秒刷新（系统时间模式下）。
- **线路筛选与快速跳转**：线路按钮分两行横向滚动，点击直接打开对应线路详情。
- **响应式布局**：适配桌面与移动端，移动端控件自动折叠。
- **回到顶部按钮**：随机线路颜色渐变，滚动超过 300px 显示。

## 使用方法

### 本地运行

1. 克隆或下载本项目到本地。
2. 使用任意静态服务器打开（推荐 VS Code 的 Live Server，或 Python 的 `http.server`）：

   ```bash
   python -m http.server 8080
   ```

3. 浏览器访问 `http://localhost:8080`。

> 直接双击 `index.html` 可能因跨域问题无法请求接口，请务必通过 HTTP 服务访问。

### 部署

将全部文件上传至任意支持静态托管的服务（如 GitHub Pages、Netlify、Vercel、对象存储等）即可。

## 配置与自定义

### 线路颜色

在 `js/constants.js` 的 `HARDCODED_COLORS` 对象中，按线路名称配置颜色值：

```javascript
const HARDCODED_COLORS = {
    "1号线": "#f3d03e",
    "2号线": "#00629b",
    // ...
};
```

新增线路时，需要同步在 `js/api.js` 的 `lineIds` 数组中添加对应的 `lineId`，并确保接口返回的线路名称经过 `normalizeLineName` 后能与 `HARDCODED_COLORS` 的键一致。

### 接口地址

在 `js/api.js` 中：

- 线路站点接口：`https://apis.gzmtr.com/app-map/metroweb/linestation`
- 首末班车接口：`https://apis.gzmtr.com/app-map/serviceTime/list/{station}`

如官方接口变更，请替换相应 URL。

### 5:00 自动刷新

在 `js/main.js` 中，`scheduleForceRefreshAt5AM()` 函数负责设置每天 5:00 的定时刷新。如需调整时间，修改该函数中的 `next5.setHours(5, 0, 0, 0)`。

### 缓存策略

- 缓存键：`gz_metro_cache`（在 `constants.js` 中定义）。
- 缓存有效期：当天有效（跨天自动清除）。
- 如需手动清除缓存，在控制台执行 `localStorage.clear()`。

## 注意事项

- 首末班车数据以广州地铁官方为准，页面仅供查询参考。
- 节假日运营时间可能调整，请以官方公告为准。
- 有轨电车、佛山地铁等线路的换乘信息部分通过人工映射实现，如与实际不符，可在 `js/ui.js` 的 `MANUAL_TRANSFERS` 中调整。
- 接口请求频率受官方限制，页面已加入重试与并发控制，请勿在短时间内频繁刷新。
